## 产品方向

继续 Svelte、Bits UI 与 Panda，不再更换整套组件技术栈。保留 Stripe-first 的克制风格，
优先减少信息层级和重复操作：列表让查询、筛选、记录和一个主操作优先于大面积概览卡；
详情强调状态、关键属性和有权限的上下文操作；设置区分未修改、脏表单、保存中、成功、
失败及只读。大范围布局或 token 变更需独立 diff 与新的真实截图，不能混入兼容修复。

Panda 的进一步价值应体现在有限语义变体和内部 slots，而不是扩大历史类名映射数量。
AI 只选择公开契约；生产鉴权、审批与操作授权不由颜色、客户端状态或模型承诺替代。
第三方设计文件仍需逐项核验许可；参考不等于允许复制和再分发素材。
