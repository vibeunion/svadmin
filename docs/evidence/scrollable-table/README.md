# Scrollable table

Generic desktop table scrolling with a mirrored horizontal scrollbar, keyboard control,
and an optional contained viewport with a sticky header.

- `scrollable-table-1440x900.png`
- `scrollable-table-1920x1080.png`

Reproduce:

```bash
bunx playwright test --config scripts/fixtures/enterprise-ui/playwright.scrollable-table.config.ts
```
