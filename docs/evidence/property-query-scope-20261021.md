## 验收

```gherkin
Given 房源、顾问、线索或看房页面
When 当前页面加载
Then 只读取当前资源，无关资源即使不可用也不产生请求和通知

Given 当前列表请求失败
When 用户再次重试失败并随后恢复
Then 只有一个内联错误，只重新请求当前列表，不创建或修改业务记录

When 前一资源读取失败或其视图参数仍存在
Then 当前页面不展示旧资源与旧错误，仅请求当前资源

Given 已保存收藏或已有筛选条件但当前没有匹配项
When 用户点击无结果区域的清除筛选
Then 清除搜索及房源条件视图，恢复全部当前资源记录，不删除已有收藏

Given 空数据且当前仅使用区域分布展示或无效视图参数
When 页面加载完成
Then 显示初始空态而不是把展示模式误报成筛选无结果
```
