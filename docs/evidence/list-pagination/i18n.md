# List component i18n

`ListPagination`, `ListFooter`, and `ScrollableTable` use the nearest `@svadmin/core/i18n` scope. System copy and accessibility labels update when that scope changes language; `label`, `note`, and `pageSizeLabel` remain host-owned values.

UI-owned keys are `listPagination.*`, `listFooter.truncated`, and `scrollableTable.*`; counts share `common.total`. A host i18n provider can translate these keys. When it returns the key unchanged, UI provides Chinese or English fallback text so older supported Core versions do not expose raw keys. Other locales can supply their own provider translations.

Browser fixtures:

- `/?view=list-pagination&locale=en&narrow=1`: English summaries, truncation guidance and controls in 240px footers.
- `/?view=scrollable-table&locale=en&top=1&native=1`: English scrollbar accessibility label and keyboard scrolling.
- Omit `locale=en` for the existing Chinese baseline.
