# 数组字段行重排

## 续接约定

- parent：`nested-array-native-contract-20261021.md`；source：继续整体企业级规范。
- reason：路线图明确保留数组重排缺口；仅移动数据而仍按位置复用 DOM 会使
  原生文件输入和未提交草稿归属错误。
- goal：上下移动采用受控且不可变的回调；边界/禁用守卫；保留被移动行的组件
  实例、附件和编辑状态；外层 JSON 顺序随宿主受控值更新。
- scope：ArrayField、array-field-feedback 单一测试文件、本文及路线图状态。
- Delegation Decision：medium / managed；主线程唯一 writer，Bohr 单人只读 verifier。
- 非目标：拖拽库、跨数组移动、服务端排序持久化、文件 multipart 索引协议。
- 不提交、发布或部署；只运行直接相关单一测试文件及 diff 检查。

## 浏览器续接约定

- parent：本文件上一轮本地契约；source：继续直到整体目标完成；
  reason：模拟器下嵌套表单通知次数和真实文件输入生命周期仍缺验收。
- scope：同一单文件测试、忽略目录 `output/playwright/array-row-reorder-20261021`、
  测试专用宿主、本证据及路线图；必要时仅修复 ArrayField 的已复现交互。
- 验收：真实受控宿主中一次移动只通知一次；文件内容和行身份在移动后对应；
  全新行不提交旧附件；嵌套 JSON、禁用和键盘操作保持一致。
- medium / managed，主线程唯一 writer，Bohr 唯一只读 verifier；不提交或部署。

## 当前结果

- `packages/ui/src/components/array-field-feedback.test.svelte.ts`：22/22 通过。
- 覆盖上下移动边界、受控不可变回调、移动行输入实例、跨移动/删除的原生文件
  归属、嵌套数组外层 JSON 提交、禁用守卫，以及外部替换行时不继承旧文件输入。
- 行 key 只复用仍由受控值保留的对象引用，或由本组件字段编辑产生的新对象；
  外部完全重建对象时不把旧位置的 DOM/文件输入错误带入新业务行。
- 字段编辑的新对象带有不可枚举 Symbol 行标记，普通 `$state` 宿主代理化后
  仍可读取；不修改宿主原对象，不强制代理化回调对象，JSON/structuredClone
  不携带内部标记。先为编辑行保留 key，再匹配其他对象，避免重复引用抢占身份。
- 组件发出的重排/增删结果带一次性不可枚举序列标记；只有宿主原样接受同一
  输出数组及其逐项对象引用时，才按输出 key 顺序恢复重复引用行。宿主拒绝或
  替换为等值外部数组时不会套用旧操作。
- `git diff --check`：通过。
- Bohr 只读复核确认旧位置 fallback 风险已关闭，随后指出代理回调兼容性和
  重复引用编辑的两个 P2；已增加定向回归并修复。宿主深拷贝回调值仍会重建
  对应行，这是引用身份契约的已知边界。
- 最终独立复核确认上述两项 P2 及重复引用移动/删除增补均通过，未发现新增
  P0/P1/P2。回调顺序校验使用 `Object.is` 明确比较身份，不触发代理等值警告。

```gherkin
Given 多行数组
When 上移或下移一行
Then 回调产生新数组而不修改宿主原值，边界操作禁用

Given 被移动行含原生附件或本地编辑草稿
When 宿主接收回调顺序
Then 行 DOM 与输入状态跟随业务行，不转移到旧位置的另一行

Given 数组禁用
When 操作移动按钮或恢复可编辑
Then 禁用时无回调，恢复后按最新受控值移动

Given 表单包含嵌套数组
When 移动内部行并接受回调
Then 外层 JSON 提交顺序一致，子字段不会重复提交
```
