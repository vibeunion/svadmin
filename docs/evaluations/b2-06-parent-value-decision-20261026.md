# B2-06 父项提交语义决定（2026-10-26）

用户要求用本地 OrbStack 收口剩余阻塞。B2-06 不是容器或服务缺口，OrbStack 不能决定父节点是否进入提交值。本决定采用已经实现并测试过的协议，不新增公共参数。

- TreeSelect 多选只提交叶子值。父项的 `true` / `mixed` / `false` 由叶子集合推导。
- 父项级联先加载完整子树，再一次性提交；加载失败不产生部分提交。
- Cascader 继续使用路径模型。只有 `changeOnSelect` 明确开启时，父级路径才进入提交值。
- 不增加 strict / non-strict，也不把禁用或未加载分支猜测成可选中。

因此“父项是否进入 value”的未决项在本轮关闭为：**默认不进入，沿用上述现有协议**。真实 Provider、读屏和发布仍另计。
