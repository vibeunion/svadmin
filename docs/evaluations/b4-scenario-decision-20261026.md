# B4 场景决定（2026-10-26）

用户要求用本地 OrbStack 收口剩余阻塞。B4 的 Scheduler、完整公式引擎、服务端工作流和服务端协作编辑没有可启动的上游服务，也不能由容器替产品选择新领域引擎。

本轮决定：

- 不新增 Scheduler、可替换排程引擎、完整公式引擎、工作流执行器或协作富文本协议。
- 已有 `KanbanBoard`、`GanttChart`、`PivotTable`、`SpreadsheetView`、`DecisionTable` 和富文本/代码编辑器保持现有本地组件边界。
- OrbStack 只用于本轮已经定义的 Auth、对象存储、记录版本和示例静态部署，不把这些结果写成 B4 领域验收。

B4-01 到 B4-04 因此不再处于“等待是否选择”的状态：本轮明确不扩展新引擎。真实排程、公式许可、工作流审计、大文档性能、读屏和发布仍未验收。
